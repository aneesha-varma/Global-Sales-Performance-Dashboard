# Global Sales Performance & Profitability Dashboard

## Objective

The objective of this project is to analyze global sales performance, profitability, customer behavior, and regional business trends using Tableau.

## Tools Used

* Tableau
* Excel / CSV
* Data Visualization
* Business Intelligence
* KPI Analytics

## Dataset Description

The dataset contains global sales transaction data including:

* Sales Amount
* Profit
* Product Category
* Customer Segment
* Country
* Region
* Discounts
* Shipping Cost

## Tableau Concepts Used

* Calculated Fields
* Filters
* Parameters
* Geographic Maps
* Dashboard Actions
* Interactive Visualizations
* Aggregations

## Dashboard Features

* KPI Cards
* Regional Sales Analysis
* Monthly Sales Trends
* Profitability Tracking
* Country-wise Sales Maps
* Customer Segment Distribution
* Product Category Insights

## Key Insights

* North America generated the highest sales.
* Electronics category delivered maximum profitability.
* High discounts reduced profit margins in some regions.
* Corporate customers generated higher average order values.
